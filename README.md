# MANJUNADHA Construction Website Version 1.0.0.0

A modern responsive landing scaffold for MANJUNADHA construction company using Tailwind CSS (CDN) + vanilla JavaScript.

## Features (Current)
- Sticky responsive navigation bar with brand, links, CTA button.
- Mobile hamburger menu with accessible toggle.
- Hero section with background image & overlay.
- Placeholder main and footer content.
 - Auto-rotating hero carousel (3 sample slides).
 - Top info bar with contact details.
 - Services section grid (6 placeholder cards).
 - Projects section showcase (6 placeholder project cards).
 - Enhanced footer with contact info, quick links, newsletter.

## Roadmap (Next)
- Services section with icon cards.
- Projects gallery with responsive grid & hover effects.
- About/company values section.
- Contact form + map embed.
- Performance optimization (self-host Tailwind build, purge unused CSS).

## Quick Start
Just open `index.html` in a browser.

## Customization
Tailwind custom colors defined inline in a small `tailwind.config` script block inside `index.html`. For production, install Tailwind locally and generate a minimized build.
